Ersetzung

Was anstelle des Suchtextes erscheint.

HTML ist erlaubt und wird ausgegeben, nicht angezeigt. Auch Code ist
möglich: Was zwischen `[php]` und `[/php]` steht, führt PMS beim Anzeigen
aus.

**Das ist mit Bedacht zu benutzen.** Code in einer Variablen läuft mit
den Rechten der Website und lässt sich von hier aus nicht mehr prüfen.
Für gleichbleibende Texte, Adressen oder Bausteine ist die Variable
gedacht; für Programmlogik ist sie der falsche Ort.
