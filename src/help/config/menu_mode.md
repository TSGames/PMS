Aufbau des Menüs

Bestimmt, ob Menüpunkte ihre Unterpunkte ausklappen können.

* **Einfaches Menü** — jeder Punkt führt direkt auf seine Seite.
* **Menü mit Unterpunkten** — ein Punkt, der auf eine Kategorie zeigt,
  kann die Unterkategorien darunter aufklappen. Welche Punkte das tun,
  wird beim einzelnen Menüeintrag festgelegt.

Beide Formen liefern dasselbe Markup: eine Liste in einem
`<nav>`-Element. Das Aussehen bestimmt also das Stylesheet des Templates,
nicht diese Einstellung. Ab acht Menüpunkten wird das Menü auf Telefonen
zugeklappt ausgeliefert und lässt sich über eine Schaltfläche öffnen.
